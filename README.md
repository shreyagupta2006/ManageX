# ManageX - Smart Workforce Management Platform

ManageX is a production-level, responsive SaaS application designed for dynamic task allocation, real-time employee monitoring, and visual performance analytics. Built using **React 19**, **Vite**, **Tailwind CSS v4**, and **Framer Motion**, it delivers a visually stunning and highly intuitive user experience inspired by Stripe, Vercel, Linear, and Notion.

---

## 🌟 Key Features

*   **Permissive Fast Authentications:** Instantly sign in to test dashboard paths without getting stuck behind strict validation. Any email containing "admin" accesses the Admin Command Center, and any other email opens the Employee Workspaces.
*   **Company Pulse Analytics (Admin):** Monitor organization metrics using custom progress SVG bar graphs, recent log monitors, and searchable/sortable employee databases.
*   **Productivity Boards (Employee):** Manage assignments through fluid Kanban status columns (New, Active, Completed, Failed).
*   **Timeline Calendars:** View task schedules mapped out in interactive monthly planner grids.
*   **Unified State Sync:** Enjoy real-time synchronization between task creations, status updates, and browser caches with floating spring toasts alerting you on every action.
*   **Light & Dark Theme Toggles:** Transition between crisp light layers and modern elevated dark surfaces with high-fidelity backdrop filters (glassmorphism).

# ManageX — Smart Workforce Management Platform

ManageX is a modern React-based Employee Management System designed to streamline workforce operations, task assignment, and team productivity through a premium SaaS-style interface.

The platform provides dedicated Admin and Employee dashboards with real-time task tracking, analytics, workflow management, and responsive user experiences inspired by modern products like Linear, Vercel, and Stripe.

## Features

### Admin Dashboard

* Assign and manage employee tasks
* Monitor team productivity
* Track task completion status
* View analytics and performance insights
* Search, filter, and manage employees
* Real-time workflow updates

### Employee Dashboard

* View assigned tasks
* Accept, complete, or fail tasks
* Track deadlines and priorities
* Monitor personal productivity metrics
* Interactive task management experience

### UI/UX Highlights

* Modern SaaS-inspired interface
* Responsive design for all devices
* Dark/Light mode support
* Smooth Framer Motion animations
* Premium dashboard layouts
* Interactive charts and task boards
* Reusable component architecture

## Tech Stack

* React.js
* Tailwind CSS
* Framer Motion
* Context API
* Lucide React Icons
* Local Storage Persistence
* Vite

## Project Goals

ManageX focuses on delivering a scalable and visually polished workforce management experience with optimized frontend architecture, modern UI systems, and seamless task workflows.
