
# ManageX — Smart Workforce Management Platform

ManageX is a modern React-based Employee Management System designed to streamline workforce operations, task assignment, and team productivity through a premium SaaS-style interface.

The platform provides dedicated Admin and Employee dashboards with real-time task tracking, analytics, workflow management, and responsive user experiences inspired by modern products like Linear, Vercel, and Stripe.

## Features

### Admin Dashboard

* Assign and manage employee tasks
* Monitor team productivity
* Track task completion status
* View analytics and performance insights
* Search, filter, and manage employees
* Real-time workflow updates

### Employee Dashboard

* View assigned tasks
* Accept, complete, or fail tasks
* Track deadlines and priorities
* Monitor personal productivity metrics
* Interactive task management experience

### UI/UX Highlights

* Modern SaaS-inspired interface
* Responsive design for all devices
* Dark/Light mode support
* Smooth Framer Motion animations
* Premium dashboard layouts
* Interactive charts and task boards
* Reusable component architecture

## Tech Stack

* React.js
* Tailwind CSS
* Framer Motion
* Context API
* Lucide React Icons
* Local Storage Persistence
* Vite

## Project Goals

ManageX focuses on delivering a scalable and visually polished workforce management experience with optimized frontend architecture, modern UI systems, and seamless task workflows.
